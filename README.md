# Static-Hand-Gesture-Detection
A capstone engineering project that utilizes Google's MediaPipe, OpenCV, and Scikit-learn pipeline for predictive gesture callouts. 
# Requirements
1. Python 3.12.10 
2. MediaPipe 0.10.14
3. OpenCV 4.11.0
4. Pandas 3.03
5. Scikit-learn 1.9.0

Ensure environment is isolated for all files 

# As final product
1. Live motion detection instead of static
2. eSpeakNG as backend for pyttsx3
3. Optimization for faster prediction
4. TTS optimization for callout speeds
5. Headless mode to offload processes
6. Project migration
