# Static-Hand-Gesture-to-TTS-Translator
An ongoing major school project that involves sign language to TTS tools for Deaf and Hard-of-Hearing students (DHH). Research is still ongoing to tackle the scale of the English vocabulary and its corresponding gestures/handspelling

Notes for git cloning

1. Do `py --list` to check installed python versions 
2. If 3.12.10 is not there, do `py install 3.12 --force`, or install via python.org
3. Direct interpreter to use that python vers by using `py -3.12 -m venv .venv`
4. Confirm interpreter version by using `py --version`
5. Install **eSpeak-ng.msi** installer through GitHub 
6. Do `pip install espeakng` in the VSCode terminal with path  directed to  "./.venv/Scripts/python.exe"
7. Open a fresh scratch terminal then run **espeak-ng**
